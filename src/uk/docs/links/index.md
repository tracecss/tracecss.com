# Посилання

Елемент посилання з `href` веде на іншу сторінку, розділ поточної сторінки або зовнішній сайт. Trace CSS добирає колір і підкреслення посилання відповідно до теми.

### Адреси посилань

```html
<a href="/uk/docs/">Відкрити швидкий старт</a>
<a href="#stani-vzayemodiyi">Переглянути стани взаємодії</a>
<a href="https://github.com/tracecss/trace">Відкрити Trace CSS на GitHub</a>
```

- [Відкрити швидкий старт](/uk/docs/)
- [Переглянути стани взаємодії](#stani-vzayemodiyi)
- [Відкрити Trace CSS на GitHub](https://github.com/tracecss/trace)

### Стани взаємодії

Наведіть курсор на посилання в прикладі. Воно змінить колір, а підкреслення стане товстішим. Якщо перейти до посилання клавішею <kbd>Tab</kbd>, навколо нього з’явиться рамка. Поки ви утримуєте кнопку миші, посилання має інший колір. Відвідані посилання типово виглядають так само, як звичайні.

Якщо в системних налаштуваннях увімкнено зменшення руху, колір змінюється відразу. У режимі примусових кольорів Trace CSS використовує системні кольори.

### Налаштування посилань

Перевизначте токени посилань у своїх стилях після Trace CSS. У прикладі збільшено відступ і товщину підкреслення.

```css
:root {
  --trace-link-underline-offset: 0.25em;
  --trace-link-underline-thickness: 0.12em;
}
```

Повний список властивостей наведено в розділі [Токени посилань](/uk/docs/customization/#tokens-links).
