# Скіл

Скіл Trace CSS допомагає агентам вибирати версію стилів, використовувати нативний HTML і підтримувані розширення, налаштовувати токени теми й усувати проблеми зі стилями.

### Встановлення

Виконайте цю команду в проєкті, де використовуєте Trace CSS:

```sh
npx skills add tracecss/trace --skill trace-css
```

Коли з’явиться запит, виберіть свого агента. Щоб встановити скіл для всіх проєктів, додайте `-g`:

```sh
npx skills add tracecss/trace --skill trace-css -g
```

Скіл містить інструкції для агента. Встановіть CSS-бібліотеку окремо:

```sh
pnpm add trace-css
```

### Використання

Попросіть агента застосувати скіл Trace CSS. Наприклад, у Codex:

```text
Використай $trace-css, щоб створити форму налаштувань із валідацією та перемикачем теми.
```

Поточний посібник описує Trace CSS 0.1.2. Він вимагає від агента перевірити встановлену бібліотеку перед вибором класів і токенів.

### Вихідний код і оновлення

Вихідний код і довідкові матеріали містяться в [каталозі skills/trace-css репозиторію бібліотеки](https://github.com/tracecss/trace/tree/main/skills/trace-css).

Після встановлення через skills CLI перевірте оновлення командою:

```sh
npx skills check
npx skills update
```

Варіанти встановлення описано в [документації skills CLI](https://github.com/vercel-labs/skills). Для роботи команди встановлення каталог скілу має бути опублікований на GitHub.
