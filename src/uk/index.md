# Trace CSS

Нативні елементи HTML, CSS-токени, світла й темна теми.

## Встановлення

```sh
pnpm add trace-css
```

Імпортуйте стилі у застосунок:

```js
import 'trace-css';
```

Вихідний код бібліотеки доступний у [репозиторії Trace CSS](https://github.com/tracecss/trace).
