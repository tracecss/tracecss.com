# Trace CSS

Native HTML elements, CSS tokens, and light and dark themes.

## Installation

```sh
pnpm add trace-css
```

Import the stylesheet in your application:

```js
import 'trace-css';
```

See the [Trace CSS repository](https://github.com/tracecss/trace) for the library source.
