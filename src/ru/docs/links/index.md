# Ссылки

Элемент ссылки с `href` ведёт на другую страницу, раздел текущей страницы или внешний сайт. Trace CSS подбирает цвет и подчёркивание ссылки под тему.

### Адреса ссылок

```html
<a href="/ru/docs/">Открыть быстрый старт</a>
<a href="#sostoyaniya-vzaimodeystviya">Посмотреть состояния взаимодействия</a>
<a href="https://github.com/tracecss/trace">Открыть Trace CSS на GitHub</a>
```

- [Открыть быстрый старт](/ru/docs/)
- [Посмотреть состояния взаимодействия](#sostoyaniya-vzaimodeystviya)
- [Открыть Trace CSS на GitHub](https://github.com/tracecss/trace)

### Состояния взаимодействия

Наведите курсор на ссылку в примере. Она изменит цвет, а подчёркивание станет толще. Если перейти к ссылке клавишей <kbd>Tab</kbd>, вокруг неё появится рамка. Пока вы удерживаете кнопку мыши, у ссылки другой цвет. Посещённые ссылки по умолчанию выглядят так же, как обычные.

Если в системных настройках включено уменьшение движения, цвет меняется сразу. В режиме принудительных цветов Trace CSS использует цвета системы.

### Настройка ссылок

Переопределите токены ссылок в своих стилях после Trace CSS. В примере увеличены отступ и толщина подчёркивания.

```css
:root {
  --trace-link-underline-offset: 0.25em;
  --trace-link-underline-thickness: 0.12em;
}
```

Полный список свойств приведён в разделе [Токены ссылок](/ru/docs/customization/#tokens-links).
