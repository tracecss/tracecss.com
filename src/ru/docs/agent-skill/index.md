# Скилл

Скилл Trace CSS помогает агентам выбирать версию стилей, использовать нативный HTML и поддерживаемые расширения, настраивать токены темы и исправлять проблемы со стилями.

### Установка

Выполните эту команду в проекте, где используете Trace CSS:

```sh
npx skills add tracecss/trace --skill trace-css
```

Когда появится запрос, выберите своего агента. Чтобы установить скилл для всех проектов, добавьте `-g`:

```sh
npx skills add tracecss/trace --skill trace-css -g
```

Скилл содержит инструкции для агента. Установите CSS-библиотеку отдельно:

```sh
pnpm add trace-css
```

### Использование

Попросите агента применить скилл Trace CSS. Например, в Codex:

```text
Используй $trace-css, чтобы создать форму настроек с валидацией и переключателем темы.
```

Текущее руководство описывает Trace CSS 0.1.2. Оно предписывает агенту проверить установленную библиотеку перед выбором классов и токенов.

### Исходный код и обновления

Исходный код и справочные материалы находятся в [каталоге skills/trace-css репозитория библиотеки](https://github.com/tracecss/trace/tree/main/skills/trace-css).

После установки через skills CLI проверьте обновления командой:

```sh
npx skills check
npx skills update
```

Варианты установки описаны в [документации skills CLI](https://github.com/vercel-labs/skills). Для работы команды установки каталог скилла должен быть опубликован на GitHub.
