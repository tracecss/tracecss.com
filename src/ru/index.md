# Trace CSS

Нативные элементы HTML, CSS-токены, светлая и тёмная темы.

## Установка

```sh
pnpm add trace-css
```

Импортируйте стили в приложение:

```js
import 'trace-css';
```

Исходный код библиотеки доступен в [репозитории Trace CSS](https://github.com/tracecss/trace).
